An end-to-end data analytics project that explores customer shopping behavior and purchasing patterns using **Python, PostgreSQL, SQL, and Power BI**.

## 📌 Project Overview

The project covers data cleaning and feature engineering in Python, business-focused analysis using SQL, and an interactive Power BI dashboard to analyze customer segments, revenue, product performance, subscription behavior, discounts, and purchasing trends.

## 🛠️ Tools & Technologies

- **Python** — Data cleaning, exploration & feature engineering
- **Pandas** — Data manipulation and analysis
- **PostgreSQL** — Database storage
- **SQL** — Business analysis and insights
- **Power BI** — Interactive dashboard & visualization

## 🎯 Outcome

The analysis identifies customer and purchasing patterns and translates them into actionable business recommendations around subscriptions, loyalty programs, discounts, product positioning, and targeted marketing.
